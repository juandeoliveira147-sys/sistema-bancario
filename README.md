# Sistema Bancário em Python (V1)

## Sobre o projeto

Este projeto simula um sistema bancário desenvolvido em Python utilizando apenas conceitos de lógica de programação, funções, dicionários, listas e estruturas de repetição.

O objetivo foi praticar a criação de um sistema com regras de negócio semelhantes às encontradas em aplicações reais de back-end, sem utilizar banco de dados ou interface gráfica.

##  Funcionalidades

* Criar conta bancária
* Login utilizando CPF e senha
* Validação de senha
* Depósito de valores
* Transferência entre contas
* Consulta de saldo
* Histórico de movimentações (extrato)
* Encerramento de sessão

##  Tecnologias utilizadas

* Python

## 📚 Conceitos praticados

* Funções
* Dicionários aninhados
* Listas
* Estruturas de repetição
* Estruturas condicionais
* Tratamento de exceções
* Validação de dados
* Organização e modularização do código

##  Limitações da versão

Esta é a primeira versão do projeto.

Os dados são armazenados apenas na memória durante a execução do programa. Ao encerrá-lo, todas as contas são perdidas.

##  Melhorias futuras

* Persistência dos dados em JSON ou banco de dados SQL
* Saque de dinheiro
* Histórico de transferências mais detalhado
* Interface gráfica ou versão Web utilizando Flask/FastAPI
* API para integração com aplicações externas


Este projeto faz parte da minha jornada de aprendizado em programação. A proposta não é apenas fazer o sistema funcionar, mas evoluir gradualmente a organização do código, aplicar boas práticas e construir uma base sólida para projetos mais completos no futuro.
